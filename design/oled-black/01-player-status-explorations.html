Player Status — three design directions

One anchor screen, rendered three ways. All three carry the same data, the same sections, and the same information architecture defined in the brief (title · name · level · energy · XP · five-stat row · Today at a Glance). Only the visual language changes. Where a direction adds anything beyond the brief, it's marked PROPOSAL below its frame.

Why this works

  • Typography does the hierarchy, not boxes. Hairline dividers separate the four zones; nothing is wrapped in a card. Reads instantly, scales to a glance.
  • XP is a 2px line. Progress is legible without a chunky meter competing with the stat values.
  • Stat row = five equal cells, hairline separators. The approved single-row layout, de-emphasised so the day's numbers lead.
  • Streaks roll up to the top per-quest runs — no invented global number, matching the brief.

Why this works

  • Solo Leveling "status window" nostalgia — kept monochrome. The System feel comes from thin bordered panels, corner ticks, bracketed ⟦ LABELS ⟧ and a monospaced numeric face, not from glow or color.
  • Level is the hero numeral. Big mono "7" anchors identity where an avatar would otherwise sit.
  • XP as a segmented tick bar reads as a game resource while staying honest to the real 540/927 value.
  • PROPOSAL The ⟦ SYSTEM ⟧ one-liner is flavour text derived from existing data (highest stat / streak). Purely cosmetic — easy to drop.

Why this works

  • Magazine hierarchy. Big light-weight name, oversized thin level numeral, generous whitespace — feels premium and personal, leans into "review progress is motivating".
  • Stats get room to breathe with larger icons and light-weight values; still the single approved row.
  • PROPOSAL A 30-day XP sparkline in Today at a Glance. Derivable from existing records, but it's a new visualisation — the brief says Status has no activity feed, so I'm flagging it rather than assuming. Trivial to remove if you want Status kept purely present-tense.
  • Uses more vertical space — best suited if you value long-term analytics on the home screen.
